# Dynamic Island — виджет для Windows

«Чёлка» в верхней части экрана, как на iOS, но в космической теме: часы,
мониторинг системы, история буфера обмена и управление медиасессией
(включая плееры в браузере).

## Готовый exe

`DynIsland.exe` — собранная one-file версия (PyInstaller). Python не нужен.

- Двойной клик по `DynIsland.exe` — виджет запускается.
- `DynIsland.exe --settings` — запуск сразу с открытым окном настроек.
- Первый запуск 2–4 секунды: файл распаковывается во временную папку.
- Пересборка после правок: `powershell -ExecutionPolicy Bypass -File build.ps1`

## Установка (запуск из исходников)

Требуется Python 3.10+ (64-bit) и Windows 10/11.

```bash
pip install -r requirements.txt
```

Библиотеки:

| Библиотека | Назначение |
|------------|-----------|
| `PyQt6`    | интерфейс (frameless + translucent окно) |
| `psutil`   | метрики CPU и RAM, имя процесса аудиосессии |
| `winrt-*`  | Windows.Media.Control — текущий трек и управление плеером |

GPU читается через NVML из драйвера NVIDIA (без запуска `nvidia-smi`).
Без NVIDIA строка GPU будет «—».

Пакеты `winrt-Windows.*` поддерживают Python 3.14. Старый монолитный `winsdk`
тоже поддерживается как запасной вариант (на 3.14 ставится только из исходников).

## Использование

- Окно в форме «чёлки» прижато к верхнему краю экрана, всегда поверх окон,
  без рамки, без записи в панели задач.
- Верхние углы вывернуты наружу: виджет «срастается» с краем экрана,
  обводка есть только по бокам и снизу.
- Верхняя панель видна всегда: часы, мини-плеер (трек, play/pause, prev/next)
  и 4 вкладки.
- Наведение мыши или клик — панель модулей плавно выезжает вниз; уход курсора —
  сворачивается. Повторный клик по активной вкладке — свернуть.
- Перетаскивание: зажать левую кнопку и вести мышью.
- Вкладки (иконки — векторные, без эмодзи):
  - **Часы** — время и дата.
  - **Монитор** — CPU / RAM / GPU, интервал опроса настраивается.
  - **Буфер** — последние 6 скопированных текстов; клик — вернуть в буфер.
  - **Медиа** — обложка-плейсхолдер, трек, play/pause, prev/next.
- Нижний ряд: громкость **приложения-источника** (Chrome/Spotify и т.п.) и
  кнопка заглушения. Системная громкость не меняется.

## Настройки

Правая кнопка мыши по виджету → **Настройки…** (или `DynIsland.exe --settings`).
Окно отдельное, без системной рамки, изменения применяются сразу.

- **Размер и позиция** — ширина, высота панели, отступ от края, привязка
  (центр/слева/справа).
- **Внешний вид** — тема, плотность фона, количество звёзд/элементов.
- **Производительность** — частота анимации 30/60 FPS, интервал опроса CPU/RAM.
- **Поведение** — раскрытие при наведении, всегда поверх окон, автоскрытие
  при перекрытии и задержка скрытия.
- **Громкость** — приложение-источник или система.
- **Система** — автозапуск вместе с Windows (реестр HKCU\...\Run).

Настройки хранятся в `%LOCALAPPDATA%\DynIsland\settings.json`.

## Темы

- **Космос** — туманность и мерцающие звёзды (фиолетово-чёрные тона).
- **Неон** — розово-голубой градиент и минималистичный город с горящими
  окнами и бегущей световой волной.
- **Закат** — красно-жёлтый градиент, солнце с пульсирующим ореолом,
  вращающимися лучами и искрами.
- **Изумруд** — насыщенно-зелёный градиент и парящие бриллианты.

Акцентный цвет темы применяется ко всем кнопкам, ползунку и обводке.

## Автоскрытие

Если «чёлку» перекрывает другое окно, она плавно уезжает за верхний край.
Достаточно навести курсор на самый верх экрана — она выезжает обратно,
а через 5 секунд без наведения снова скрывается. Если ничего не перекрывает,
виджет виден всегда.

## Оформление

- Фон — космос в выбранной теме: туманность (кэшируется в QPixmap) и живые
  мерцающие звёзды, которые перерисовываются на таймере 30/60 FPS.
  GIF не нужен: анимация процедурная.
- Плавные анимации: выезд панели, смена вкладок, подсветка иконок,
  доводка полос CPU/RAM/GPU, «дыхание» обложки.

## Как устроено (кратко)

```
main.py                  точка входа (QApplication, QSS, лог ошибок)
island/styles.py         стили виджета и окна настроек (акцент из темы)
island/settings.py       Settings, JSON, автозапуск через реестр
island/settings_dialog.py отдельное окно настроек
island/widget.py         окно-«чёлка», форма, векторные иконки, анимации, drag
island/volume.py         громкость приложения (WASAPI IAudioSessionManager2)
island/workers.py        фоновые потоки:
                         - SystemMonitorWorker (QThread, интервал из настроек)
                         - ClipboardWorker (QThread, Win32-опрос раз в 400 мс)
                         - MediaWorker (threading.Thread + asyncio, winrt)
island/system.py         ctypes: системная громкость, clipboard, GPU (NVML)
```

UI-поток никогда не опрашивает API: потоки спят и шлют готовые значения
по сигналам, поэтому CPU в простое ≈ 0%. Внешние процессы не запускаются,
поэтому окно консоли не мелькает.
